# 40 Podcast Topics: Interview Subjects, Not Propositions (2026 Edition)

A debate topic is a yes/no claim that two sides fight over. A podcast needs the
opposite: a subject a host can open up and a guest can answer at length, in
persona, without anyone having to win. So these are phrased as open questions
(*what*, *how*, *why*, *what would*), never "Should X be banned?".

Each topic carries a suggested **guest** count. The host is not counted; it
always takes its own seat, so `- Guests: 2` means a three-seat run. A podcast
allows 1–4 guests.

Format: a numbered `N. Title` line followed by a `- Guests: N` line, the same
shape as [`Topics.md`](Topics.md) with `Guests` in place of `Debaters`, so a
future podcast launcher can reuse `debate.ps1`'s topic parser by swapping one
word. A used topic gets a ✅ appended to its title line. Nothing picks from this
file automatically yet: copy a line into `--topic` or the `/orchestrate` form.
